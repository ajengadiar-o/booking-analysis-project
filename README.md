# Booking Drop-off Analysis

## Background
Not all users complete the booking process in online travel platforms. Many drop off before completing transactions, impacting conversion rates.

## Objective
- Measure cancellation rate
- Identify factors affecting drop-off
- Provide data-driven recommendations

## Tools
- Python (Google Colab)
- Pandas, Numpy
- Matplotlib, Seaborn

## Dataset
Hotel Booking Dataset

## Analysis
### 1. Cancellation Rate
27.49% of bookings are canceled

### 2. Lead Time
Longer lead times are associated with higher cancellation

### 3. Customer Type
Transient customers have the highest cancellation rate

## Insight
Drop-off is driven by:
- time uncertainty (long lead time)
- user flexibility (transient)

## Recommendations
- Send reminders before check-in
- Apply stricter booking policies
- Improve checkout experience
